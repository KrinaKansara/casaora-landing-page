# Casaora — Home Decor Landing Page 🏡

## Project Overview

Casaora is a fictional home decor discovery and shopping app. This landing page concept introduces the brand, helps visitors explore decorating styles, and shows how thoughtful, budget-conscious updates can make a home feel personal.

## Target Audience

- Renters looking to personalize their space
- First-time homeowners
- Adults aged 25–40 interested in home decor
- People seeking inspiration and practical ideas for a realistic budget

## Design Features

- Desktop landing page design with a responsive-friendly Auto Layout structure
- Header with Casaora wordmark, navigation links, and calls to action
- Hero section with headline, supporting copy, and warm interior imagery
- Three decor inspiration cards: Calm & collected, Warm & lived-in, and Bold & expressive
- Editorial room-refresh feature
- Concept customer testimonial
- Footer with navigation and newsletter area
- Separate frame with reusable components
- Design notes describing the audience and design rationale
- Consistent typography, colors, spacing, and visual hierarchy

## Design Tools

- Figma
- Auto Layout
- Reusable components
- Shared color and typography styles

## Reusable Components

The design includes four reusable components used throughout the page, with a separate frame for reviewing the component set.

## Design Rationale

Casaora uses warm cream backgrounds, terracotta accents, forest green, and natural interior imagery to create a calm and welcoming feel. A clear editorial hierarchy and reusable Auto Layout sections make the page easy to scan and adaptable to different screen widths.
